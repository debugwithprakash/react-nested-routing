# React Nested Routing & Navigation

A hands-on React project built to demonstrate **nested routing** and **dynamic navbar navigation** using React Router.

## 🚀 Features
- **Nested Routes:** Utilizes `<Outlet />` for rendering nested component layouts seamlessly.
- **Dynamic Navbar:** Responsive navigation bar with active route highlighting using `NavLink`.
- **Clean Structure:** Modular folder hierarchy for components, layouts, and route definitions.

## 🛠️ Tech Stack
- **React.js**
- **React Router DOM**
- **CSS / Tailwind CSS**
